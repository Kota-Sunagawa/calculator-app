# シンプル電卓（Simple Calculator）

HTML / CSS / JavaScript の基礎を学ぶために作った、シンプルな電卓アプリです。
フレームワークやビルドツールは一切使わず、素の Web 技術だけで動いています。

## 概要

ブラウザ上で動く電卓アプリです。四則演算（たし算・ひき算・かけ算・わり算）に加えて、
パーセント計算やキーボード入力にも対応しています。
「まずは基本を手を動かして理解する」ことを目的に、学習用として作成しました。

## 主な機能

- 四則演算（+ − × ÷）
- パーセント計算（%）
- 小数点の入力
- 1文字削除（⌫ バックスペース）
- 全クリア（C）
- キーボードでの操作（数字キー、+ - * /、Enter、Backspace、Escape）
- ゼロ除算をした場合の「エラー」表示

## ローカルでの実行方法

インストールやビルドは不要です。`index.html` をブラウザで開くだけで動きます。

1. このフォルダをダウンロード、またはクローンする
2. `index.html` をダブルクリックしてブラウザで開く

それだけで電卓が使えます。

## 使っている技術

フレームワークやライブラリは使わず、以下の3つだけで作られています。

- **HTML** — 電卓の見た目の骨組み（`index.html`）
- **CSS** — デザインとレイアウト（`style.css`）
- **JavaScript** — 計算のロジックと画面の更新（`script.js`、フレームワークなしの素の JS）

フォントの読み込みにのみ Google Fonts を利用しています。

## ファイル構成

```
calculator-app/
├── index.html   # 画面の構造（ボタンや表示部分）
├── style.css    # 見た目のスタイル
└── script.js    # 電卓の計算ロジック
```

## 学びながら作った点

- ボタンの状態管理を1つのオブジェクト（`state`）にまとめて、表示処理（`render`）を分離することで
  コードの見通しをよくすることを意識しました。
- `data-*` 属性（`data-num` / `data-op` / `data-action`）を使い、ボタンごとに個別のイベントを
  書くのではなく、共通の処理で振り分ける書き方を試しています。
- マウス操作だけでなく、キーボード入力にも対応させることで `keydown` イベントの扱い方を学びました。

まだ改善できる点も多いプロジェクトですが、基礎を固めるための一歩として作りました。
